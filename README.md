# WhiteList CRM API

Решение задания Б (Software Developer): REST API организаций, звонков и встреч.
Node.js 24.12+ с нативным запуском TypeScript и встроенной SQLite; внешних зависимостей нет.

## План реализации

1. SQL-схема и транзакции.
2. Правила рабочих часов, бронирование и история.
3. HTTP API и проверка входных данных.
4. Тесты бизнес-правил, гонок и HTTP-контракта.
5. Инструкция, примеры и REFLECTION.md.

Ограничение объёма: только API; авторизация, роли, очереди, уведомления и интерфейс не входят в задание.
